Yours, not rented

Your content never touches our servers. The files are already in your repo — JustJSON only edits them.

// zero infra

No server, account, or token

It runs on your machine and sends data nowhere. Start it, use it, close it.

// portable

Git-friendly, goes anywhere

Plain JSON diffs and versions cleanly. Import it in your build, deploy it wherever you like.

What it does

A real CMS experience — backed by plain files

From schema to content, without writing a line of config.

Schema

Visual schema builder

Define collections and fields in the UI. Pick a field type from icon cards — text, number, relation, image…

Content

Searchable content table

Entries list with title, slug and date; search and edit instantly. Content — not a pile of slugs.

Writing

Rich-text editor

Headings, bold, lists, quotes — WYSIWYG. But it's saved to disk as clean, diffable Markdown.

Media

Image uploads

Drop an image; it's resized to WebP right in the browser and written under content/media/.

Types

Type-safe output

Generates types.ts from your schema, so your content is fully typed in your own project.

Output

The endpoint is yours

Wherever you put the JSON becomes your API — repo raw, jsDelivr, your own build. Or export a ZIP.

How it works

Your own backend in three steps

1

Start

npx @kdrgny/justjson init — begin from a template (blog, cv) or from scratch.

2

Design & fill

npx @kdrgny/justjson opens the editor in your browser. Design the schema, enter content, upload images.

3

Ship

content/*.json is ready on disk. Commit, deploy, import it in your build — your flow.
