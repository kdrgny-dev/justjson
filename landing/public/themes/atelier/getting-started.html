Getting started

Relay forwards webhooks from the services you use to the endpoints you control, and keeps a record of every delivery. This page gets you from nothing to a delivered event in about five minutes.

Install the CLI

npm install -g @relay/cli
relay login

relay login opens a browser once and stores a token in ~/.relay/config.json. Everything after this works offline until the token expires.

Create your first endpoint

An endpoint is a URL Relay delivers to, plus the events it should receive.

relay endpoints create \
  --url https://api.example.com/hooks/stripe \
  --events payment.succeeded,payment.failed

Relay answers with an endpoint id and a signing secret. Store the secret the way you store database passwords — you need it to verify that a request really came from Relay.

Send a test event

relay send payment.succeeded --data '{"amount": 4200}'

Watch it arrive with relay tail. If the endpoint returns anything other than a 2xx, Relay retries on the schedule described in Retries and delivery.
