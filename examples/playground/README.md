# JustJSON playground

A ready-to-run JustJSON project. Open it in your browser with no install:

[![Open in StackBlitz](https://developer.stackblitz.com/img/open_in_stackblitz.svg)](https://stackblitz.com/github/kdrgny-dev/justjson/tree/main/examples/playground)

It boots the editor with a small blog already in `content/` — edit an entry,
build the schema, restyle it in **Design**. Everything you change is written
back to `content/*.json`, exactly like on your own machine.

Locally it's the same one command:

```bash
npx @kdrgny/justjson
```
